Channel Management

Manage guild data channels and permissions

Note: Channel management requires Discord bot integration for actual channel operations. This interface provides a preview of available commands.
Setup Guild Channel
Right-click channel → Copy ID (requires Developer Mode)
Channel Information
Get information about a guild channel
Channel Permissions
Channel permissions require Discord bot integration to manage actual permissions.

Available Discord bot commands:

  • /setupchannel #channel - Setup guild channel
  • /channelinfo #channel - Get channel information
  • /setchannelpermissions #channel - Set channel permissions
  • /lockchannel #channel - Lock channel
  • /unlockchannel #channel - Unlock channel
  • /archivechannel #channel - Archive channel
Guild Channels
Channel list requires Discord bot integration to display actual guild channels.

Use /listchannels in Discord to see all guild channels.

Bulk Channel Operations
Bulk operations require Discord bot integration for actual execution.

Available bulk commands:

  • /setupallchannels - Setup all guild channels
  • /lockallchannels - Lock all guild channels
  • /unlockallchannels - Unlock all guild channels
  • /archiveallchannels - Archive all inactive channels
