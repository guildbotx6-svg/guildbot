Help & Documentation

Complete guide to using the Free Fire Guild Manager

Quick Start Guide
1. Setup Your Guild Channel

Use /setupchannel #your-channel to initialize a channel for guild management.

2. Add Guild Members

Use /guildupdates to open the modal and paste your guild member list.

3. Manage Your Guild

Use commands like /currentmembers, /editguild, and /guildhistory.

4. Moderate Players

Use /warnuid and /banuid for player moderation.

5. Export Data

Use /export or /exportall to download guild data.

6. Access Web Interface

Visit the web interface for visual data management and analysis.

Command Categories

Basic Commands:
  • /guildupdates - Update guild member list
  • /currentmembers - Display current members
  • /editguild - Edit guild information
  • /guildhistory - View guild history
Advanced Commands:
  • /resethistory - Reset guild history
  • /export - Export guild data
  • /exportall - Export all guild data

Warning System:
  • /warnuid <uid> <reason> - Warn a player
  • /warnings <uid> - View player warnings
  • /listwarnings - List all warnings
Ban System:
  • /banuid <uid> <reason> - Ban a player
  • /listbans - List all bans
  • Global Bans: Bans apply across all channels

Commander Commands:
  • /addcommander @user - Grant commander role
  • /removecommander @user - Remove commander role
  • /listcommanders - List all commanders
Head Commander Commands:
  • /addheadcommander @user - Grant head commander (Admin only)
  • /removeheadcommander @user - Remove head commander (Admin only)
  • /listheadcommanders - List head commanders

Setup Commands:
  • /setupchannel #channel - Setup guild channel
  • /channelinfo #channel - Get channel info
  • /listchannels - List all guild channels
Permission Commands:
  • /setchannelpermissions #channel - Set permissions
  • /lockchannel #channel - Lock channel
  • /unlockchannel #channel - Unlock channel
  • /archivechannel #channel - Archive channel

Data Cleanup:
  • /clearguild #channel - Clear guild data
  • /clearwarnings #channel [uid] - Clear warnings
  • /clearbans #channel [uid] - Clear bans
  • /clearhistory #channel - Clear history
Bulk Cleanup:
  • /clearallguilds - Clear all guild data
  • /clearallwarnings - Clear all warnings
  • /clearallbans - Clear all bans
  • /clearallhistory - Clear all history

Information:
  • /help [topic] - Get help
  • /ping - Check bot latency
  • /status - Server status
  • /userinfo @user - User information
System:
  • /roleinfo @user - Role information
  • /sysinfo - System information (Admin only)
  • /botinfo - Bot information
Data Formats
Guild Member List Format:

When using /guildupdates, paste member data in this format:

Player Name 1 - UID: 1234567890
Player Name 2 - UID: 1234567891
Player Name 3 - UID: 1234567892

Each line should contain: Player Name - UID: PlayerUID

Bound List Format:

For bound member lists, use the same format as guild members.

Permissions & Roles
Role Hierarchy:
  • Everyone: Basic commands (help, ping, status)
  • Commander: Guild management, moderation
  • Head Commander: All commands except admin functions
  • Administrator: Full access including system commands
Channel-Scoped Data:
  • Each Discord channel has separate guild data
  • Warnings and bans are channel-specific
  • Global bans apply across all channels
  • Commander roles are server-wide
Troubleshooting

  • Bot not responding: Check if bot is online and has proper permissions
  • Commands not working: Ensure you have the required role
  • Modal errors: Check message length (max 2000 characters)
  • Data not saving: Verify database connection and permissions

  • Invalid UID format: UIDs must be numeric
  • Duplicate entries: System prevents duplicate UIDs
  • Missing data: Check if channel is properly set up
  • Export failures: Ensure bot has file upload permissions

  • Access denied: Check your server roles
  • Channel permissions: Bot needs read/write permissions
  • Role hierarchy: Higher roles can override lower ones
  • Admin commands: Require server administrator role
Support & Contact
Getting Help:
  • Use /help command in Discord
  • Check this documentation
  • Review command permissions
  • Test with basic commands first
Report Issues:
  • Include error messages
  • Describe what you were doing
  • Mention your server setup
  • Check bot status with /status
