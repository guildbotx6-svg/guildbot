Commander Management

Manage commander roles and permissions

Note: Commander management requires Discord bot integration for actual role assignment. This interface provides a preview of available commands.
Add Commander
Right-click user → Copy ID (requires Developer Mode)
Remove Commander
Right-click user → Copy ID (requires Developer Mode)
Current Commanders
Commander list requires Discord bot integration to display actual users with the Commander role.

This feature is available through the Discord bot commands:

  • /addcommander @user - Grant commander role
  • /removecommander @user - Remove commander role
  • /listcommanders - List all commanders
Add Head Commander

Remove Head Commander
Requires Administrator permissions
Current Head Commanders
Head Commander list requires Discord bot integration to display actual users with the Head Commander role.

This feature is available through the Discord bot commands:

  • /addheadcommander @user - Grant head commander role (Admin only)
  • /removeheadcommander @user - Remove head commander role (Admin only)
  • /listheadcommanders - List all head commanders
