All Available Commands
These commands are available through the Discord bot interface.
Guild Management:
  • /guildupdates - Update guild data
  • /currentmembers - Show current members
  • /editguild - Edit guild information
  • /guildhistory - View guild history
  • /resethistory - Reset guild history
Moderation:
  • /warnuid - Warn a player
  • /warnings - List warnings
  • /listwarnings - List all warnings
  • /banuid - Ban a player
  • /listbans - List bans
Utilities:
  • /help - Get help
  • /ping - Check latency
  • /status - Server status
  • /userinfo - User information
  • /roleinfo - Role information
  • /sysinfo - System info
Commander Commands:
  • /addcommander - Add commander
  • /removecommander - Remove commander
  • /listcommanders - List commanders
  • /addheadcommander - Add head commander
  • /removeheadcommander - Remove head commander
  • /listheadcommanders - List head commanders
Channel Commands:
  • /setupchannel - Setup channel
  • /channelinfo - Channel information
  • /listchannels - List channels
  • /setchannelpermissions - Set permissions
  • /lockchannel - Lock channel
  • /unlockchannel - Unlock channel
Cleanup Commands:
  • /clearguild - Clear guild data
  • /clearwarnings - Clear warnings
  • /clearbans - Clear bans
  • /clearhistory - Clear history
  • /clearallguilds - Clear all guilds
  • /clearallwarnings - Clear all warnings
  • /clearallbans - Clear all bans
  • /clearallhistory - Clear all history
Export Commands:
  • /export - Export guild data
  • /exportall - Export all data
