Available Cleanup Commands

These commands are available through the Discord bot:

Guild Data:
  • /clearguild #channel - Clear guild data
  • /clearallguilds - Clear all guild data
Warnings:
  • /clearwarnings #channel [uid] - Clear warnings
  • /clearallwarnings - Clear all warnings
Bans:
  • /clearbans #channel [uid] - Clear bans
  • /clearallbans - Clear all bans
History:
  • /clearhistory #channel - Clear history
  • /clearallhistory - Clear all history
